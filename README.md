# Nameplate Addon

A custom nameplate addon for World of Warcraft.

## Installation

1. Download the latest release
2. Extract the contents to your World of Warcraft/Interface/AddOns directory
3. Enable the addon in-game through the AddOns menu

## Features

- Basic nameplate functionality
- Customizable settings (coming soon)

## Requirements

- World of Warcraft 10.2.0 or later
